Check what you downloaded

In PowerShell, from the folder you saved it in:

Get-FileHash .\ConstructionPaper.exe -Algorithm SHA256

The Hash it prints should match the SHA-256 above, ignoring case. If it does not, delete the file and download it again. That hash is the one written into the release notes when the build was published; this page does not compute it from the file.

The size above is counted the way Windows Explorer counts it, in units of 1,024 bytes. GitHub's release listing uses units of 1,000, so the two give different numbers for the same file.

First run

  1. Put the executable in its own folder — it keeps its settings, layers, profiles and tile cache beside itself.
  2. The browser may block the file first as one that is not commonly downloaded; choose Keep. On launch, Windows shows Windows protected your PC; choose More info, then Run anyway. Both warnings mean the same thing: the executable is not code-signed, so Windows has never seen it before. The SHA-256 above is how you verify it instead.
  3. You will be asked for a license. Import the .igl file you were sent, or paste the key. Without one the program will not open. A key binds to the first computer that runs it, so if it is needed on a second machine, email chris@chrisputnam.me for a key for that machine rather than copying the license across.

Every build is made and tested on 64-bit Windows 11. Windows 10 has not been tested; if you try it there, email chris@chrisputnam.me and say how it went.

Renaming photos needs nothing else installed. Reading GPS out of video files needs ffmpeg on the machine — it is not bundled with the executable, and without it videos are left alone.
