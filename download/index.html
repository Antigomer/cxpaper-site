Check what you downloaded

In PowerShell, from the folder you saved it in:

Get-FileHash .\ConstructionPaper.exe -Algorithm SHA256

The Hash it prints should match the SHA-256 above, ignoring case. If it does not, delete the file and download it again.

First run

  1. Put the executable in its own folder — it keeps its settings, layers, profiles and tile cache beside itself.
  2. Windows SmartScreen will warn you about an unrecognised publisher. Choose More info, then Run anyway. The executable is not code-signed yet; the SHA-256 above is how you verify it instead.
  3. You will be asked for a license. Import the .igl file you were sent, or paste the key. Without one the program will not open.
