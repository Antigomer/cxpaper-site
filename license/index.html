How it works

A license is a small signed file. It carries an id, an expiry, whether the copy has to check in, and a machine field that is blank, one specific fingerprint, or a wildcard. The program verifies that signature before it opens. Those three machine values are the three kinds:

RedeemableBlank. Binds to the first computer that runs it. The binding is recorded beside the program, not counted on a server.
LockedOne fingerprint. Issued for one specific machine and runs only there.
MasterWildcard. Runs on any number of computers, never binds, and never runs the check-in clock. Revocable by id like any other key.

The status file

status.json is the revocation list. It is signed with the same key as the licenses themselves, so a tampered or invented file is rejected by every copy of the program. What a signature cannot do is force an answer, or prove on its own that the copy that arrived is the newest one. A host that cannot be reached leaves a withdrawn key looking good. Revocation depends on a copy reaching this address.

What happens when that answer does not arrive depends on the key. A license that has never reached this host is never blocked for it; one that has keeps working for thirty days past its last successful check, and is then blocked. A strict check-in key, which is issued deliberately, starts that clock on the day it is issued instead of at its first successful check. A master license ignores the clock entirely.

What is stored on your machine

The license gate touches only its own files, and only beside the executable: the license itself (license.igl, which it writes when a key is imported or pasted), the binding record, the cached status, and the machine fingerprint. On the author's own copy it also appends the ledger of keys it has issued. It never touches your photos, layers, profiles or output. That is a hard rule, not a current behavior.

The fingerprint is a SHA-256 of two values Windows already exposes about the computer: its machine GUID and its computer name. It stays on the machine. The status check is a plain download of the file above, and there is nothing on this host that could receive anything back.
