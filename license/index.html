What happens next

  1. Copy the key this page gives you.
  2. Download the file and put it in a folder of its own — it keeps its settings, layers, profiles and tile cache beside itself.
  3. The browser may block it first as a file that is not commonly downloaded; choose Keep. On launch, Windows shows Windows protected your PC; choose More info, then Run anyway. Both warnings mean the same thing: the executable is not code-signed, so Windows has never seen it before. The SHA-256 below is how you verify it instead.
  4. It asks for a license. Click Paste license key and paste what you copied. If you were sent an .igl file instead, choose Import license file and pick it.

The key locks to the first computer that opens it. If you need it on a second machine, ask and you will get a second key — copying the license across will not work.

The program checks in with this site about once a month. It does not need the internet while you work; it needs it once in the month. Somewhere with no signal at all for weeks on end is worth mentioning when you ask, and the key can be issued to suit.

Check what you downloaded

In PowerShell, from the folder you saved it in:

Get-FileHash .\ConstructionPaper.exe -Algorithm SHA256

The Hash it prints should match the SHA-256 above, ignoring case. If it does not, delete the file and download it again. That hash is the one written into the release notes when the build was published; this page does not compute it from the file.

The size above is counted the way Windows Explorer counts it, in units of 1,024 bytes. GitHub's release listing uses units of 1,000, so the two give different numbers for the same file.

Every build is made and tested on 64-bit Windows 11. Windows 10 has not been tested; if you try it there, email chris@chrisputnam.me and say how it went.

Renaming photos needs nothing else installed. Reading GPS out of video files needs ffmpeg on the machine — it is not bundled with the executable, and without it videos are left alone.
