What happens next

  1. Copy the key this page gives you.
  2. Download the file and put it in a folder of its own — it keeps its settings, layers, profiles and tile cache beside itself.
  3. Windows will try to stop you twice, and both times it is the same complaint — it has never seen this program before. Your browser may call it uncommon: choose Keep. Then Windows says Windows protected your PC: choose More info, then Run anyway. If you would rather check the file yourself first, there is a way to at the bottom of this page.
  4. It asks for a license. Click Paste license key and paste what you copied. If you were sent an .igl file instead, choose Import license file and pick it.

The key locks to the first computer that opens it. If you need it on a second machine, ask and you will get a second key — copying the license across will not work.

The program checks in with this site about once a month. It does not need the internet while you work; it needs it once in the month. Somewhere with no signal at all for weeks on end is worth mentioning when you ask, and the key can be issued to suit.

Checking the file is the one I put out, and what changed in it

The program is not code-signed, so Windows has never seen it before and will say so. If you would rather check the file yourself than take Windows' word for it, every release carries a fingerprint — a long string that changes if so much as one byte of the file does.

Fingerprint…

In PowerShell, in the folder you saved it in:

Get-FileHash .\ConstructionPaper.exe -Algorithm SHA256

What it prints should match the fingerprint above, upper or lower case does not matter. If it does not match, delete the file and download it again.

One oddity worth knowing if you compare: the size above is counted the way Windows Explorer counts it. The release page counts it the other way, so the same file shows two different numbers.
