Request a license

Construction Paper is invitation-only right now. Ask for a license and you will get a file back to open it with.

Request a license

That opens an email. Say who you are and what project you are on, and send it.

When the license arrives

  1. Save the file it comes with somewhere you can find it.
  2. Open Construction Paper. It asks for a license.
  3. Choose Import license file and pick that file.

It only has to be done once, on that computer. If you need it on a second computer, ask and you will get a second one — the license is tied to the machine it is opened on.
